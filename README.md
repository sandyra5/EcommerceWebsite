# E-Commerce Website

A web-based e-commerce application developed using **ASP.NET Web Forms, C#, ADO.NET, SQL Server, and WCF**.

## Features

- User registration and login
- Product browsing and search
- Product details
- Shopping cart management
- Order placement
- Online payment using WCF
- Admin product management
- CRUD operations

## Technologies Used

- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Backend:** ASP.NET Web Forms, C#
- **Database:** SQL Server
- **Data Access:** ADO.NET
- **Payment Service:** WCF


## Setup

1. Clone the repository.
2. Open the E-Commerce project in Visual Studio.
3. Configure the database connection in the Connection Class.
4. Create the required SQL Server database and tables.
5. Open and run the WCF Web Application.
6. Run the E-Commerce application.
